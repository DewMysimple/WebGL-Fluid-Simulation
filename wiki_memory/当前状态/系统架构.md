# 系统架构 / System architecture

> 本次基线已于 2026-09-24 获用户集中确认，当前有效。
> Baseline confirmed by the user on 2026-09-24; active.

依赖方向：`main → app → features/fluid → engine → webgl/shaders`；界面通过 `i18n` 使用中英词典，设置使用 `shared/storage`。引擎不能反向依赖 React、界面或持久化。

| 模块 | 责任 | 源码 |
| --- | --- | --- |
| App | 页面与快捷键、PNG 下载 | `src/app/` |
| Feature | React 控件、配置持久化、引擎生命周期 Hook | `src/features/fluid/` |
| Engine | RAF、输入队列、能力适配、上下文恢复 | `src/engine/FluidEngine.ts` |
| Solver | 涡旋、压力迭代、梯度投影、平流 | `src/engine/solver.ts` |
| Renderer | 辉光、光束、明暗、合成 | `src/engine/renderer.ts` |
| Device | GPU 程序、纹理/FBO、几何与清理 | `src/engine/webgl/` |
| GLSL | 20 个独立 shader 文件 | `src/engine/shaders/` |

配置从 React 传给 `setConfig`，每帧不触发 React 状态更新。引擎控制资源，React Hook 负责挂载/卸载；截图在独立 RGBA8 帧缓冲中绘制并导出 Blob。

React controls configure a standalone engine; frame state stays outside React. GPU resources have explicit owners and cleanup. Detailed architecture is in `docs/architecture.md`.
