# 项目概览 / Project overview

> 本次基线已于 2026-09-24 获用户集中确认，当前有效。
> Baseline confirmed by the user on 2026-09-24; active.

项目：WebGL-Fluid-Simulation / 流体实验室（Fluid Lab）。目标：把独立全局脚本重构为易开发维护的工程，并提供中英双语和仓库内工程记忆。

当前代码：React + Vite + TypeScript + 原生 WebGL；单页面纯前端，不依赖后端、密钥或外部运行时服务。保留原流体算法、辉光、光束、触摸和截图，新增预设、参数持久化和兼容错误提示。

The code is a client-only, bilingual fluid playground. React owns UI; an independent TypeScript engine owns GPU simulation and lifecycle. Exact versions are in the lockfile.

入口：`src/main.tsx`、`src/app/App.tsx`、`src/engine/FluidEngine.ts`。开发：`npm ci` → `npm run dev`。发布：构建后托管 `dist/`。

面向使用者：希望体验交互流体的访问者，以及继续扩展界面、算法或渲染效果的开发者。上游作者 Pavel Dobryakov，保留 MIT 许可。
