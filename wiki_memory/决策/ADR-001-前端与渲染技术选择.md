# ADR-001：前端与渲染技术选择 / Frontend and rendering stack

> 本次基线已于 2026-09-24 获用户集中确认，当前有效。
> Baseline confirmed by the user on 2026-09-24; active.

## 背景 / Context

原工程为全局 `script.js`、内嵌 GLSL、dat.gui 与 HTML 内嵌样式。用户希望现代、标准、易维护，并允许判断 React/Vite/Three.js/WebGL 组合。

## 选择 / Decision

已实现 React 19 + Vite 8 + TypeScript 6 + 原生 WebGL/GLSL。TypeScript 使用 typescript-eslint 支持的稳定版本；精确依赖以 `package-lock.json` 为准。

The current single-screen client application uses React for UI and an imperative WebGL solver. There is no routing, server rendering or remote data layer to justify a larger framework.

## 理由与取舍 / Rationale

算法是二维全屏纹理计算。Three.js 不会消除求解器与 GLSL 的维护负担，当前 WebGLRenderer 仅支持 WebGL 2；保留原生实现可维持 WebGL 1 兼容。未来确需三维网格/相机/材质时再引入适配器。WebGPU 需要单独重写和设备验证，本轮不采用。

- [React 独立应用与 Vite](https://react.dev/learn/build-a-react-app-from-scratch)
- [Vite guide](https://vite.dev/guide/)
- [Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)

## 影响和验证 / Consequences and validation

运行从直接静态脚本改为 Vite 开发/构建，部署目录改为 `dist/`。UI、引擎、GLSL、GPU 资源各有入口。验证类型、Lint、单元测试、真实浏览器、生产子目录加载；维护细节见 `docs/architecture.md`。
