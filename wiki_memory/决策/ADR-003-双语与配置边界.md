# ADR-003：双语与配置边界 / Localization and preferences

> 本次基线已于 2026-09-24 获用户集中确认，当前有效。
> Baseline confirmed by the user on 2026-09-24; active.

## 选择 / Decision

小型双语 UI 使用静态 TypeScript 词典，英文必须满足中文键集合，类型与测试共同检查缺失键。中文/English 同步更新标题、文档语言、控件、提示和错误；用户选择优先于浏览器语言。

React 是用户设置的来源，`sanitizeConfig` 在持久化和引擎边界校验有限范围与颜色，`adaptConfig` 生成设备适配后的有效配置。`shared/storage` 处理存储异常，设置对象带 schema version。

Typed dictionaries keep the current small bilingual interface complete. Preferences have a versioned schema, validated bounds, and safe localStorage access. Localization and storage never enter the solver.

## 取舍 / Trade-offs

目前无复数或复杂消息插值，不增加 i18next。语言/内容变复杂时，可以替换 i18n 层而无需改变 GPU 引擎。配置刷新不重建画布，语言切换不重启模拟。

## 验证 / Validation

`src/i18n/messages.test.ts`、`src/engine/config.test.ts` 和浏览器持久化/存储失败/双语测试。
