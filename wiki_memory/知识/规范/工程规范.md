# 工程规范 / Engineering conventions

> 本次基线已于 2026-09-24 获用户集中确认，当前有效。
> Baseline confirmed by the user on 2026-09-24; active.

- TypeScript strict，禁止用 any 或 ts-nocheck 掩盖边界错误。
- 遵循 app → feature → engine → GPU 单向依赖。GLSL 单独存放，保留许可说明。
- 数字范围与配置校验集中在 `config.ts`；翻译集中在 `i18n`；GPU 资源集中分配/释放。
- 验证真实行为，不以浅层 DOM 存在代替渲染成功。必要时检查 PNG 像素和资源计数。
- 使用 .editorconfig / Prettier / ESLint；依赖变更更新 package-lock，不引入不需要的框架。
- 上游 MIT 版权头、LICENSE 和来源链接必须保留。

Keep modules focused and contracts explicit. No React imports in the engine, no per-frame state in React, no user-facing strings scattered across components. Preserve attribution and validate resource cleanup for GPU changes.
