# 界面与国际化 / Interface and localization

> 本次基线已于 2026-09-24 获用户集中确认，当前有效。
> Baseline confirmed by the user on 2026-09-24; active.

`src/app/App.tsx` 装配画布、控制面板、工具栏、快捷键、错误与下载。`src/features/fluid/Controls.tsx` 提供受控参数；`settings.ts` 管理预设与版本化偏好；`useFluidEngine.ts` 连接 React 生命周期。

`src/i18n/messages.ts` 是文案来源，`useLocale.ts` 负责选择、存储、html lang 和标题。所有产品文案必须双语，不把实现细节暴露为产品流程。新增参数要同时更新配置、标签、控件和相关测试。

State changes update engine settings; the render loop stays outside React. Language switches do not recreate the canvas. Chinese and English cover visible labels, hints, errors and accessibility labels.

快捷键忽略 input/select/textarea/button/link/summary 和 contentEditable；指针输入仅绑定 canvas。移动端默认收起面板并选用 512 染料精度。减少动态效果偏好默认暂停。
