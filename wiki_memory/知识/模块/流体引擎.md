# 流体引擎 / Fluid engine

> 本次基线已于 2026-09-24 获用户集中确认，当前有效。
> Baseline confirmed by the user on 2026-09-24; active.

入口 `src/engine/index.ts` 导出 `FluidEngine` 与配置类型。公共操作：`setConfig`、`randomSplats`、`clear`、`capture`、`dispose`。`capture` 返回 PNG Blob，下载由 UI 完成。

`FluidEngine.ts`：画布大小、RAF、暂停/后台停帧、上下文恢复、状态回调。`input.ts`：Pointer Events、多点指针捕获和坐标换算。`solver.ts`：压力投影与平流。`renderer.ts`：Bloom/Sunrays/显示。`capture.ts`：离屏导出、翻转像素与透明预乘还原。

Frame pipeline: input splats → curl → vorticity → divergence → pressure decay/Jacobi → gradient subtraction → velocity/dye advection → lighting → composition.

`webgl/context.ts` 负责能力检测与 FBO 探测清理；`Device.ts` 统一所有权；`Program.ts` 编译/链接与释放；`Target.ts` 管理单/双帧缓冲。重复挂载不能留下 RAF、输入事件或 GPU 对象。新增纹理优先通过 Device 分配。

修改物理参数看 config/solver；修改视觉效果看 renderer/shaders；修改输入看 input/math；修改截图看 capture。测试见 `src/engine/*.test.ts` 与 `tests/e2e/`。
