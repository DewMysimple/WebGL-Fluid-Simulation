# 开发与验证 / Development workflow

> 本次基线已于 2026-09-24 获用户集中确认，当前有效。
> Baseline confirmed by the user on 2026-09-24; active.

环境：Node 24 + npm；`npm ci` 安装精确依赖，`npm run dev` 启动。完整说明在 `docs/development.md`。

| 命令 | 用途 |
| --- | --- |
| `npm run check` | TypeScript、ESLint、Vitest、Vite build |
| `npm run format:check` | 格式检查 |
| `npm run test:e2e` | 开发模式行为、WebGL 与资源生命周期 |
| `npm run test:production` | 真实 dist 子目录加载与双语 |
| `npm run memory:index` | 刷新唯一日志 MOC |
| `npm run memory:check` | 检查记忆结构 |
| `npm run memory:test` | 测试记忆索引工具 |

首次浏览器测试运行前执行 `npx playwright install chromium`；Linux CI 使用 `--with-deps`。CI 配置在 `.github/workflows/ci.yml`。

Testing uses Chromium/SwiftShader. The unsupported-device test intentionally logs an error. Real mobile GPUs and other browser engines need independent checks. Do not turn emulation into a claim of device coverage.

完成实质任务自动追加日志和刷新索引；长期结论遵循 `wiki_memory/AGENTS.md` 的用户确认规则。

用户已明确要求：每次完整对话结束时，对本轮仓库改动追加日志、更新索引，提交并推送到当前分支的上游。执行前审阅暂存范围；无关文件保持不动。上游缺失或拒绝时不得强推，说明情况并请求处理。

After every completed conversation that changes the repository, log and index the work, commit its intentional changes, and push the current branch's configured upstream. Review staging; preserve unrelated files and never force-push.
