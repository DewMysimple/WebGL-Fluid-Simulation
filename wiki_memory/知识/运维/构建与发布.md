# 构建与发布 / Build and deployment

> 本次基线已于 2026-09-24 获用户集中确认，当前有效。
> Baseline confirmed by the user on 2026-09-24; active.

`npm run build` 输出 `dist/`，`npm run preview` 只用于本地检查。静态主机上传 dist 内容即可；没有服务端进程、API 或必需环境变量。Vite 使用相对 base，`/fluid/` 子目录有生产浏览器测试。

The source root no longer works as a standalone static site. Build and publish `dist/`. CI validates only; no deployment is performed by this refactor.

原 GitHub Pages 若直接发布源码分支，需改为构建产物；不应把 node_modules、源码记忆目录或测试结果复制到线上。

排查：设备不支持 half-float FBO 时检查硬件加速；性能低时降低画质和光效；上下文丢失会重新生成画面但保留设置；本地存储被阻止时仍可操作。

源码：`vite.config.ts`、`package.json`、`.github/workflows/ci.yml`。详细操作：`docs/development.md`。
