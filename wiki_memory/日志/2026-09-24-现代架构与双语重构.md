# 2026-09-24｜现代架构与双语重构

- 时间：2026-09-24（北京时间）
- 类型：feature
- 状态：完成并封存
- 目标：将原始全局脚本改造为现代可维护工程，提供中英双语与模板驱动的工程记忆。

## 已确认的授权与决策

- 用户授权判断技术组合、实施架构重构、中英双语，并按提供的工程记忆模板构建记忆。

## 检查与操作

- 检查原 HTML、全局脚本、dat.gui、静态资源、MIT 许可及 Git 状态；起始工作区无用户未提交修改。
- 读取桌面记忆模板的协议、当前状态、模板与索引工具；保持原始来源只读。
- 核对官方 React/Vite/Three.js 文档与 npm peerDependencies。选用 React/Vite/TypeScript + 原生 WebGL，保留二维求解算法与 WebGL 1 回退。
- 从原脚本提取 20 个 GLSL，分离 UI、引擎、solver、renderer、GPU 资源、输入和截图。
- 完成双语、预设、版本化设置、PNG 导出、上下文恢复、资源清理、移动布局和无能力错误处理。
- 新增工具链、CI、双语 README、架构/开发文档及工程记忆。
- 锁文件 tarball 地址规范为官方 npm 源，执行 npm ci 验证可复现。
- 修正模板工具生成 MOC 表格时未转义 Obsidian 别名竖线的问题；仓库副本增加回归测试，原模板不变。
